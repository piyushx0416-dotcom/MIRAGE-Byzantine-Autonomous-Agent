ENGINE 01 // DETERMINISTIC

Classical BFT Distance Outlier Detector

Calculates pairwise Euclidean distances across all broadcast coordinates. Drones whose average deviation exceeds the swarm's global clustered average by Δ > threshold are flagged as Byzantine.

DEVIATION THRESHOLD FORMULA
avg_deviation(d_i) > global_avg + θ_threshold (60.0)
classical_detection.py
class ClassicalByzantineDetector:
    def __init__(self, threshold=60):
        self.threshold = threshold
        self.suspected = set()

    def detect(self, drones):
        self.suspected = set()
        for drone in drones:
            rx, ry = drone.get_reported_position()
            deviations = [
                np.sqrt((rx - o.get_reported_position()[0])**2 + 
                        (ry - o.get_reported_position()[1])**2)
                for o in drones if o.id != drone.id
            ]
            if np.mean(deviations) > global_avg + self.threshold:
                self.suspected.add(drone.id)
        return self.suspected
